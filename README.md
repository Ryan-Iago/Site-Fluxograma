# 🌿 IA para Proteção do Meio Ambiente

Este projeto exibe como a **Inteligência Artificial (IA)** pode auxiliar o ser humano a preservar o meio ambiente através de **duas rotas principais de atuação**:
1. **Monitoramento & Prevenção:** Foco em combate ao desmatamento e queimadas.
2. **Gestão de Recursos:** Foco em eficiência energética e agricultura sustentável.

---

## 🚀 Como publicar este projeto no GitHub Pages

1. Crie um novo repositório no seu GitHub.
2. Adicione os arquivos `index.html`, `style.css` e este `README.md`.
3. Vá nas **Settings** (Configurações) do repositório no GitHub.
4. No menu lateral, acesse **Pages**.
5. Em **Build and deployment** > **Branch**, escolha `main` (ou `master`) e salve.
6. O GitHub irá gerar o link direto para o seu site!
